# Priorização MoSCoW - VITUS 💜🌿

Este documento define o que é essencial para manter a estabilidade do Vitus e o que são as próximas ambições.

## 📦 MUST HAVE (O CORAÇÃO DO VITUS - ESTÁVEL)
*Sem isso, o app perde sua razão de existir. Estas funcionalidades estão BLINDADAS.*
- [x] Scanner de Medicamentos (Lupa Mágica)
- [x] Sistema de Alarmes Flexíveis (Injeção de horas)
- [x] Login Seguro com Supabase
- [x] Agenda Inteligente (O que tomar hoje)
- [x] Registro de Sinais Vitais (Pressão/Batimentos)
- [x] Compatibilidade Web e Mobile (Expo Everywhere)

## 📦 SHOULD HAVE (DEVERIA TER - PRÓXIMOS PASSOS)
*Adicionam muito valor, mas não quebram o uso básico se não existirem ainda.*
- [ ] **Family Link:** Alguém cuidando de quem cuida (Dashboard para familiares).
- [ ] **Exportação Excel Avançada:** Além do PDF, dados brutos para médicos.
- [ ] **Histórico de Medicamentos Melhorado:** Ver log de meses anteriores com facilidade.

## 📦 COULD HAVE (PODERIA TER - ENCANTAMENTO)
*O "UAU" que diferencia o Vitus de um despertador comum.*
- [ ] **Gamificação (Minhas Vitórias):** Medalhas, streaks e animações de celebração.
- [ ] **IA de Auxílio:** Perguntar ao app sobre contraindicações básicas (via API ANVISA/LLM).
- [ ] **Widgets de Tela Inicial:** Ver o próximo remédio sem abrir o app.

## 📦 WON'T HAVE (NÃO AGORA - FUTURO DISTANTE)
*Ideias legais, mas que podem distrair do foco em idosos agora.*
- [ ] Social Networking (Comunidade de usuários).
- [ ] Integração com Smartwatches (Apple Watch/Google Fit) - *Aguardando demanda*.
- [ ] E-commerce de farmácia embutido.
